## Full description (for a dedicated project page)

**DineFlow — Restaurant Ordering & Management Platform**

DineFlow is a complete restaurant SaaS product covering both sides of the
business: the customer ordering experience and the internal tools a restaurant
needs to run day to day.

**Customer-facing:** menu browsing with search, category, and price filtering;
food detail pages; a persistent cart; a full checkout flow supporting delivery
and pickup; and a real-time visual order tracker.

**Admin-facing:** menu and category management with full CRUD; an order pipeline
with status controls that update the customer's tracking view instantly; a
payments overview; and a sales analytics dashboard with revenue and order trend
charts.

The project was deliberately built in two phases — a fully working frontend
prototype on realistic mock data, followed by a systematic migration to a real
PostgreSQL database (hosted on Supabase), authentication, and live deployment on
Vercel. Every piece of application state was structured around the eventual
database schema from the outset, so the backend migration was a contained,
predictable piece of work rather than a rewrite.

**Tech stack:** Next.js 14 (App Router), TypeScript, Tailwind CSS, Prisma ORM,
PostgreSQL (Supabase), Supabase Storage, NextAuth.js, Recharts, deployed on Vercel.
